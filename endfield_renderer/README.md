# 终末地一键渲染 1.1.4 · 中文版

支持尼可、提弗洛斯、索米和自定义角色的材质配置。插件名称、侧栏、按钮、参数、材质用途、提示和进度信息采用简体中文。安装后无需连接 9876 或 9877 端口。

## 安装与运行

请按 [快速开始](快速开始.md) 安装。本插件**仅支持 GOO 引擎（Goo Engine 4.4.x）**。在其 3D 视图按 **N → 终末地**，选择角色和输出目录，点击 **一键终末地渲染**。

**自动识别材质与贴图** 默认开启。主按钮自动读取原材质和基础颜色，识别材质用途、头部骨骼及配套贴图，并补全缺失的必需辅助图。无需先逐行设置映射或勾选启用。

**处理范围** 支持三种方式：**优先选中或当前角色** 优先处理选中的可识别角色，未选中时优先当前活动角色，最后才扫描场景；**仅选中的角色** 处理所选网格并尝试自动识别；**全部已识别角色** 扫描有头骨与面部材质的角色及已有映射。静态自定义角色请使用“仅选中的角色”。

主按钮依次加载内置参考资源、应用材质和面部适配、生成缺失贴图、设置可编辑修改器与控制点、绑定角色主光、校验网格、打包贴图、使用现有相机渲染预览。工程副本默认不保存；如需结果文件，可手动保存工程，或勾选高级设置中的 **完成后另存工程副本**。

三个专用角色按原始材质集合识别，重命名网格物体不影响识别。尼可保留暖色肤色、克制的鼻部明暗及下颌到颈部的衔接，法线修正可恢复。提弗洛斯优先使用原生贴图；索米转换 RMO 数据并适配面部着色。

原始骨架、形态键、基础顶点坐标和原 UV 层保持可编辑。索米新增 `EF_FaceUV` 层。复制和适配的修改器保持启用，不会烘焙到基础网格。

主面板提供独立的 **一键导入修改器**。直接选中原始角色即可使用：识别材质区域和头部骨骼、加载内置参考资源、绑定主光、导入身体接缝焊接、日光方向、脸方向、描边属性、平滑描边、光线投射、头发阴影代理和眼透位移。阴影代理需要头发，眼透位移需要眼睛和眉毛用途。原始材质槽、着色节点、骨架与形态键保留，修改器保持启用、可编辑；重复点击更新同一组修改器。此按钮不渲染，也不生成贴图；缺图补全由“一键终末地渲染”执行。

## 自定义角色

本版按**每个角色一个完整网格**处理，网格需有 UV 和区分部位的材质槽。绑定骨架的角色需要头部骨骼，也支持静态网格。分件角色需由使用者提前整理；插件不自动合并网格或修改骨架。

1. 选中网格，保持 **自动识别材质与贴图** 开启，点击主按钮即可。若想先查看识别结果，展开 **自定义角色材质映射** 并点击 **自动识别材质与贴图**。
2. 材质用途依据中、英、日名称、基础颜色文件名及原材质参数识别。支持面部、皮肤、头发、眼睛、眉睫、口腔眼白、布料、金属、毛绒、玻璃和透明叠加层。识别不到具体部位时使用通用布料参数，并在该行注明；可手动改为正确用途或 **保留原材质**。
3. 自动保留原材质的不透明度，例如 `涙`、`照れ`、`赤面` 等禁用表情层不会被自动打开；头发阴影和眼白阴影按透明叠加层处理。
4. 点击材质行可查看识别依据、已关联贴图和待生成通道。可手动指定基础颜色、法线、P、HN、自发光；展开 **独立 PBR 通道贴图** 可指定粗糙度、金属度、AO 或 RMO。后续自动识别保留手动修改的用途、图像选择和不透明度。
5. 自动识别常见 `頭`、`Head`、`头` 等头骨。至少需要一个实际分配给面片的面部材质；若面部或头骨无法识别，会提示在映射表补充。常见 MMD 模型为 −Y 朝前、+Z 朝上，其他模型可手动调整方向轴。
6. **保存材质映射／加载材质映射** 使用 JSON 文件，按材质和图像数据块名称匹配。自动识别开启时导入的用途优先；关闭自动识别时，检查后手动勾选 **启用此映射**。

自定义面部采用通用卡通着色，不套用尼可的鼻部局部效果或其他角色的面部 SDF。脸型、光照及颈部衔接仍需单独检查。内置角色的重复实例应分别设置自定义映射；自定义角色副本会在下次运行时获得独立控制点。

**1.1.2 肤色与环境光修正：** 自定义面部与身体共用参考皮肤的环境光、日光和投影计算，柔化面部法线并保留下颌转折。原先独立面部着色只切换明暗，无法跟随材质预览 HDRI 的强度与颜色，造成脸、颈和身体脱节。默认 **脸部肤色匹配身体** 在实际 UV 面片内按面积采样，只校准原图色差；身体的色调参数在共享光照内应用一次，原图保持不变。无可用身体材质时采用中性原图校准和参考皮肤参数。面部支持手动肤色、亮度与法线柔化，重复配置保留修改。

**仅配置角色：** 两个一键按钮均不导入环境模型、舞台、世界环境或其他角色，不创建相机，也不重设已有灯光、世界、色彩管理或构图。优先使用指定日光或场景已有日光，缺少时只补建角色着色必需的日光和方向控制点。为支持参考节点，渲染引擎设为 Goo EEVEE。没有相机时跳过预览，仍完成角色配置，报告记录跳过原因。旧版舞台选项即使保存在工程中也不再执行。

自定义头发关闭其他角色的肤色融合，采用中性高光颜色并收窄轮廓光；布料、金属和玻璃等材质降低过宽、过强的白色轮廓光。升级时只替换仍等于旧版预设的相关值，保留已手动调整的参数。尼可、提弗洛斯与索米的专用配置保持原有参数。

## 贴图通道

基础颜色使用 sRGB。法线采用 OpenGL 切线空间（+Y）；法线、P、HN 和自发光数据使用 Non-Color。

| 贴图 | 通道含义 |
| --- | --- |
| 身体 P | R 金属度，G 辅助／保留通道（中性值 0.5），B 环境遮蔽，A 光滑度 |
| 头发 P | R 方向法线混合，G 高光遮罩，B 环境遮蔽，A 高光衰减 |
| 头发 HN | RG、BA 分别存储两组法线的 XY 分量 |
| 索米 RMO 转换 | P = (RMO.G, 0.5, RMO.B, 1 − RMO.R) |

生成的法线、粗糙度、金属度、微细凹陷环境遮蔽、P 和 HN 是根据原色及材质用途得到的估算结果，并非游戏原图；环境遮蔽也不是光线追踪烘焙。JSON 清单记录来源哈希、生成器版本、种子、分辨率及通道统计。文件名相同但内容不同的原图使用独立输出。

识别优先级为：手动指定 → 原材质对应输入的图像连接 → 基础颜色目录及相邻纹理目录中具有相同完整名称前缀的文件。支持 `_D/_N/_P/_HN/_E`、`_basecolor/_normal/_roughness/_metallic/_ao/_rmo` 等命名，避免把其他角色或其他图集的贴图配错。纹理仍须可读取或已打包到工程。

身体类材质需要 P/N，头发需要 P/HN；只生成缺失的必需项。已有粗糙度、金属度、AO 或 RMO 可合成为 P，保留已有通道。自发光为可选输入，缺失时不推测发光区域。面部、眼睛、口腔及透明叠加层保留基础颜色着色。无可用基础颜色图时以材质纯色生成占位图，并在识别信息中提示。生成过程不覆盖原始贴图，修改原色后按内容哈希重新生成。

完整生成程序在 `maps.py` 中，仅使用 Goo 自带的 NumPy。所有 Python 源码也会写入配置后工程的 `EF Source / …` 文本数据块。

## 参数、预设与恢复

面板提供 **最大光滑度、最大金属度、法线强度、轮廓光强度、整体阴影亮度** 等材质控制项。选择对应面部材质后，可调节 **肤色调节、面部亮度、面部法线柔化；尼可专用配置另有阴影颜色、阴影柔和度、鼻部阴影及鼻部高光**。

**保留已调整的材质参数** 会在重复运行时保留未连接的节点组输入和修改器参数。直接修改的节点连线仍会被重建，建议另存副本。场景中的灯光、世界环境、色彩管理和相机始终保留。**保存外观预设／加载外观预设** 保存材质组和修改器输入，不包含灯光或图像。

输出目录包含 `textures/`、JSON 校验报告，以及按选项生成的 PNG 预览和结果工程。找不到外部文件的已打包原图导出到输出目录，不覆盖原图。预览后恢复原渲染参数。

**1.1.3 不再创建自动备份，也不自动回滚或打开任何工程文件。** 已移除回滚按钮和“正在准备备份”流程。点击后直接在当前场景配置角色。取消或报错时立即释放运行状态，保留当前场景及已完成的配置；错误在面板显示，并尽可能写入 `last_error.txt`。按 Esc 在当前步骤完成后停止后续步骤，单张贴图生成或渲染期间需要等待该步骤结束。重新打开工程或重新启用插件时会清理旧版遗留的忙碌状态。

如果主光源指针指向已移出场景的旧灯光，自动改用当前场景的日光；没有日光时只补建角色所需日光。不会重新导入旧灯光所属的集合。导入角色后未选中物体时，“优先选中或当前角色”会使用当前活动角色，避免同时重配其他角色。

**恢复选中角色的原始材质** 仍可恢复当前工程保留的原材质槽及尼可下颌法线，并禁用终末地修改器。这是当前场景内的材质操作，不创建或打开备份文件。

## 升级与兼容性

**仅支持 GOO 引擎（Goo Engine 4.4.x）**，实测 Windows / Goo Engine 4.4.3。普通 Blender 和 Cycles 缺少所需节点，本版不支持其他 Goo 版本。角色导入和骨架由使用者准备。

1.1.0 保留 1.0.x 的操作符、属性、材质用途枚举顺序、节点接口及预设 JSON 标识，新增检测状态和独立 PBR 贴图字段。旧工程和映射可继续使用。侧栏参数显示为中文，内部接口与参考资源名称保持兼容。升级后若侧栏未刷新，请重启 Goo Engine。

## 源码

插件包含着色器、修改器和面部适配数据，不包含三个角色模型或角色纹理集，也不授予第三方角色资产的使用权。

源码：`ui.py` 界面与操作符；`i18n.py` 中文参数及状态显示；`workflow.py` 流程；`runtime.py` 运行状态及错误记录；`autodetect.py` 自动识别；`custom.py` 自定义映射；`skin_match.py` 肤色采样校准与自定义高光；`profiles.py` 材质表；`core.py` 材质；`maps.py` 贴图生成；`modifiers.py` 修改器；`modifier_import.py` 独立修改器导入；`faces.py` 尼可面部；`face_transfer.py` 遮罩适配；`style.py` 风格预设；`studio.py` 最小角色主光支持；`resources.py` 资源定位和恢复。
