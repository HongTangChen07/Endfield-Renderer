# 终末地一键渲染 1.1.4 · 中文版

**仅支持 GOO 引擎（Goo Engine 4.4.x，实测 4.4.3）。**

1. **编辑 → 偏好设置 → 插件 → 从磁盘安装**，选择 `endfield_one_click_1_1_4.zip`，启用 **终末地一键渲染**。
2. 3D 视图按 **N**，打开 **终末地** 页签。
3. 选择角色网格，或将 **处理范围** 设为 **全部已识别角色**，设置 **输出目录**。
4. 保持 **自动识别材质与贴图** 开启，点击 **一键终末地渲染**。

插件直接应用参考材质、生成缺失贴图、设置可编辑修改器、绑定头部与主光方向、校验网格、使用已有相机渲染预览；默认不另存工程。完整生成程序保留在 `maps.py`，并随其他源码写入工程文本数据。

**尼可、提弗洛斯、索米**支持现有材质表自动识别。尼可包含已修正的暖色肤色、鼻部明暗及下颌与脖子的衔接。修改器保持启用、可编辑。

其他角色：选中**包含完整角色的单个网格**，使用 **仅选中的角色**，直接点击主按钮。插件自动识别材质用途、基础颜色、配套贴图和头骨；优先使用已有贴图，缺失的 P/N/HN 按用途从基础颜色生成。已禁用的表情层保持原不透明度。自发光可选，不自动推测。

要先检查结果，可展开 **自定义角色材质映射 → 自动识别材质与贴图**。每行显示识别依据和缺图情况；可以手动修正，后续识别会保留手动修改。无法判断部位时采用通用布料参数并提示。

只需要修改器时，点击主面板的 **一键导入修改器**。自动使用内置参考资源，原材质、骨架和形态键保持不变；修改器启用且可编辑，重复导入不叠加。此按钮直接导入并校验，不渲染或生成贴图。

至少需要一个实际分配给面片的 **面部** 材质。不需要转换的材质设为 **保留原材质**。通过 **保存材质映射／加载材质映射** 可复用设置。自定义面部采用通用卡通着色，仍需检查脸型及面部与脖子的衔接。

1.1.2 默认 **脸部肤色匹配身体**：按当前角色 UV 采样校准原图色差，面部与身体共享环境光和日光响应，保留眼口细节和柔和面部明暗。自定义头发使用中性高光，并降低头发及服饰过强的轮廓光。再次一键运行可升级旧默认参数；手动调整的材质参数继续保留。

插件仅配置角色，不导入环境、舞台、世界或其他角色，也不创建相机。复用已有日光，缺少时只补建着色必需的日光和控制点。没有相机时跳过预览，仍完成配置。保留现有世界、灯光、色彩管理和构图。

**高级设置** 可选择主光、贴图尺寸和预览采样数，也可 **保存外观预设／加载外观预设**。选中面部材质后可以调整肤色、面部亮度和法线柔化程度。

**1.1.3 已移除自动备份和回滚按钮。** 按 Esc 或遇到错误时停止后续步骤，保留当前场景和已完成的配置，不会自动打开其他文件。旧版卡住的忙碌状态会在升级或载入工程时清理。

旧主光已移出场景时自动重选有效日光，没有时只创建所需日光。新导入的活动角色即使没有被选中，也会优先处理；需要批量处理时选择“全部已识别角色”。

需要保存最终工程时自行保存，或在高级设置中勾选 **完成后另存工程副本**。

升级自 1.0.x 时，已有材质映射、贴图路径及参数标识保持兼容。安装后若侧栏未刷新，可重启 Goo Engine。普通 Blender 和 Cycles 不支持所需的 Goo 节点。

完整使用说明见 [README.md](README.md)。
